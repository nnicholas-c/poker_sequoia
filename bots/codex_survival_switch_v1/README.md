# Survival switch v1

Before the paid places: protect stacks against large repeated aggression, avoid unopened 23–30 BB jams, retain normal steals and short-stack play. Once only paid players remain: reduce risk premium and widen pressure; heads-up prioritizes first place.

Built from the supplied GTO final; keeps its correctness fixes. See [paired test results and limitations](../../arena/benchmarks/survival-switch/README.md). No tournament submission is performed by adding this file.
